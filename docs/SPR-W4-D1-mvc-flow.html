SPR-W4-D1-01：HTTP RequestからResponseまで

HTTP Request

ブラウザがHTTPメソッド・URL・queryを送信。
GET /employees/1
→

DispatcherServlet

Spring MVCの入口。URLとメソッドからControllerを選び、処理を呼び出す。
→

Controller

PathVariable / RequestParamをJava引数として受け取り、戻り値を返す。
→

HTTP Response

ステータス・ヘッダー・本文をブラウザへ返す。
例：200 + JSON
呼び出しと変換
Tomcat → DispatcherServlet → HandlerMappingで選択 → HandlerAdapterで呼び出し。
@RestControllerの戻り値は本文として扱い、HttpMessageConverterがStringやJSONへ変換する。
今回の確認：/hello、/employees/{id}、/employees?department=xxx
